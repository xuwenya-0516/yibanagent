# 依伴儿 AI

一个使用通义千问（Qwen）的患者端健康对话应用。前端不接触 API Key，所有模型请求均由 Python 服务端转发。

## 启动

1. 打开 `.env`，把阿里云百炼 API Key 填到：

   ```env
   DASHSCOPE_API_KEY=sk-你的-key
   ```

2. 在当前目录启动服务：

   ```bash
   python3 server.py
   ```

3. 打开患者端 <http://127.0.0.1:8000>，医生端为 <http://127.0.0.1:8000/doctor.html>。

修改 `.env` 后需要重启服务。按 `Ctrl + C` 可停止服务。

## 配置

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DASHSCOPE_API_KEY` | 空 | 阿里云百炼 API Key，必填 |
| `QWEN_MODEL` | `qwen-plus` | 使用的千问模型 |
| `PRO_ANALYZER_MODEL` | `qwen-plus` | PRO 语义匹配与结构化提取模型 |
| `QWEN_BASE_URL` | 中国内地公共接口 | OpenAI 兼容接口根地址 |
| `QWEN_SYSTEM_PROMPT` | 依伴儿助手提示词 | 助手身份与回答风格 |
| `YIBAN_DB_PATH` | `data/yiban.db` | 对话、PRO 追问和回答的 SQLite 数据库 |
| `HOST` | `127.0.0.1` | 本地监听地址 |
| `PORT` | `8000` | 本地监听端口 |

## 已包含

- 流式逐字回复
- 多轮上下文
- 本地保存聊天记录
- 停止生成、清空对话
- 症状、用药和健康科普的可选引导
- 报告选择、复诊提醒与患者端快捷入口
- 移动端适配
- API Key 仅保存在服务端 `.env`
- 对话中识别 38 项乳腺癌 PRO 相关问题，由 AI 在普通聊天里自然追问
- 在对应 AI 回复下方显示纵向 PRO 单选项；点击后作为患者正常回复继续对话
- 从患者点击或自然语言回答中提取标准答案，记录触发原话、AI 追问和回答原话
- 医生端展示当前负担、变化趋势、分维度结果与原对话证据链

## PRO 研判边界

当前版本按用户提供的“两周回顾期”量表实现。医生端结果是随访筛查与趋势提示，不是医学诊断；风险分层规则会在页面中显示版本号，正式临床使用前需要由医院确认量表版本、计分规则、阈值、告警流程和数据合规要求。
